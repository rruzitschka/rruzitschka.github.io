SendLog — CSS Mock Proposals

Three design directions exploring a more compact, less colorful landing page. Click any card to open the mock.

Mock A — Stone

Warm neutral · Single slate accent

Warm off-white background, slate-600 as the single accent color replacing all blue/orange. Cards use a left border instead of a top border. Spacing reduced to ~70% of current. Feature grid at 260px min column. 2-column FAQ grid.

Mock B — Editorial

Black + white · Dark green accent

Near-black text on white background. Single dark forest-green accent. Feature grid is a flush 4-column tile layout (no gaps, 1px borders between cells). "What's New" rendered as a timeline instead of cards. Uppercase tracked section labels.

Mock C — Night

Full dark theme · Muted blue-gray

Dark background throughout (#0d1117). Muted steel-blue used sparingly for links and the Web App nav item only. Screenshots desaturated. Download button is outline-only. "What's New" uses a clean version/date header with a left-bordered list.
