Questions & Answers

Can I add photos to my climbing routes?

Yes. Attach photos to each climb — stored locally and synced if Cloud Sync is enabled.

Is my data secure?

All data lives locally by default. Cloud Sync uses Firebase with Sign in with Apple — no password created or stored.

How does Cloud Sync work?

Enable in Settings → Cloud Sync. Sign in with Apple. Climbs, ascents, photos sync in background. Fully offline at all times.

Can I export my data?

Yes — CSV/ZIP from Settings. Works with or without Cloud Sync.

What is the Central Route Database?

A shared community route collection. Search when logging to pre-fill details and link to the shared record.

Does SendLog require internet?

No. Fully offline. Internet is only used for optional Cloud Sync.

Can I delete my cloud account?

Yes — Settings → Delete My Account. Server data deleted; local history preserved.

Can I track projects separately?

Yes. The Projects tab manages active, completed, and abandoned projects.
